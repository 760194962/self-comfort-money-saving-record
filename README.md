# 省钱存折 · Savings Passbook

一个记录"自己省了多少钱"的小工具。买机票省了 250、忍住没乱买一件衣服……随手记一笔，打开就能看到自己攒下的 **"省钱存款"**。哪天感觉亏了，翻出来看看余额还有这么多，心里就踏实了。主打**正反馈**——每次存入都有金币飞溅、余额跳动、金额向上飘、里程碑进度条前进，攒到里程碑还有特别庆祝 🎉。反馈以**动效与数字**为主，不堆砌夸奖文案。

> 纯粹的心理账户，你的**记账数据不上传**、只存在自己的浏览器里；仅在获取实时/历史汇率时会联网向公开汇率接口请求一次（可离线降级到手动汇率）。

## 功能

- 🪙 **省钱余额** —— 老式存折风格，打开第一眼就是攒下的总数
- ⚡ **一键记账** —— 金额 + 备注 + 快捷标签（机票 / 打折 / 忍住没买 / 返现…）
- 🛒 **也能记花费** —— 顶部一键切换「省了一笔 / 花了一笔」；花费从存款余额里扣掉，流水里以红色「−」显示，让余额是真实的「净省」。花费也有自己的快捷标签（餐饮 / 交通 / 日用…）
- 🏷️ **常用备注自动填充** —— 备注下方自动列出你**最常用**的历史备注（金色圆点标记，按使用频次排序），点一下即填入，无需重复打字；新用户则回落到内置快捷标签
- 🎉 **满满正反馈** —— 金币动画、余额跳动、里程碑进度条与金额飘字（尽量用动效和数字，不依赖文字夸奖，天然更适合日后做多语言）
- 🌍 **多币种 + 真实汇率** —— 支持人民币、美元、港币、日元；汇率取自**欧洲央行公开数据（Frankfurter API，免密钥）**，打开时自动联网更新，也可手动改
- 📅 **自定义日期 + 历史汇率** —— 记账可选任意过去的日期；补记过去的一笔时，会**自动联网获取那天的真实汇率**并快照进这笔，「按当时汇率」回看就是当时省了多少
- ✏️ **编辑过去的记录** —— 点流水里任意一笔即可修改日期、金额、币种、备注，以及这笔用的「当时汇率」
- 💾 **导入 / 导出** —— 一键导出备份（复制文字或下载 .json），换设备时导入即可
- 🌗 **深浅色** —— 跟随系统，也可手动切换

## 使用

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建。

手机上建议**添加到主屏幕**，会带上专属图标（金色 ¥ 币）并以全屏 App 形式打开，像个真 App 一样随手就能记。

> 主屏幕图标依赖同目录下的 `favicon.svg` / `apple-touch-icon.png` / `icon-192.png` / `icon-512.png` / `manifest.webmanifest`，用 GitHub Pages 等静态托管打开即可生效。

### 汇率说明

汇率来自 [Frankfurter](https://www.frankfurter.app/)（欧洲央行 ECB 公开数据，免密钥、支持历史日期）：

- **当前汇率** —— 打开应用时若数据超过 6 小时会自动联网更新；也可在 ⚙ 设置里点「联网更新汇率」手动刷新，或直接手改。
- **历史汇率** —— 补记过去某天的一笔时，会自动获取那天的真实汇率并**快照**进这笔；在编辑面板里改日期也会自动取当天汇率。周末/节假日会回落到最近的工作日汇率。
- **离线降级** —— 取不到（离线、接口不可用）时会保留当前/手填的汇率，功能不受影响。

每笔记录都保存自己那一份汇率快照，所以即便以后汇率变了，「按当时汇率」回看依然是当时的数值。

### 数据与备份

所有数据保存在浏览器本地存储（localStorage）里：

- 换设备、清理浏览器数据前，记得用 ⚙ → **导出** 做一份备份
- 在新设备打开后用 ⚙ → **导入** 粘回去即可

## 技术

零依赖、零构建的纯静态页面：核心逻辑全在单个 `index.html`（HTML + CSS + 原生 JS）里，另附一套图标与 PWA `manifest.webmanifest`，用于添加到主屏幕时的专属图标与全屏体验。字体用 Google Fonts 的 Bricolage Grotesque 与 Space Mono。汇率通过浏览器直接请求 Frankfurter API（`https://api.frankfurter.app`，无需密钥），历史汇率会缓存到本地以减少重复请求。

## 规划

- 🌐 **多语言** —— 界面文案后续计划抽成可切换的语言包。反馈已改为以动效、图标和数字为主，不依赖夸奖文案，为多语言打好了基础。
