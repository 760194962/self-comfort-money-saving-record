# 省钱存折 · Savings Passbook

一个记录"自己省了多少钱"的小工具。买机票省了 250、忍住没乱买一件衣服……随手记一笔，打开就能看到自己攒下的 **"省钱存款"**。哪天感觉亏了，翻出来看看余额还有这么多，心里就踏实了。主打**正反馈**——每次存入都有金币飞溅、余额跳动、随机鼓励语，攒到里程碑还有特别庆祝 🎉。

> 纯粹的心理账户，不联网、不上传，数据只存在你自己的浏览器里。

## 功能

- 🪙 **省钱余额** —— 老式存折风格，打开第一眼就是攒下的总数
- ⚡ **一键记账** —— 金额 + 备注 + 快捷标签（机票 / 打折 / 忍住没买 / 返现…）
- 🎉 **满满正反馈** —— 金币动画、余额跳动、随机夸奖、里程碑庆祝
- 🌍 **多币种** —— 支持人民币、美元、港币、日元四种；**记录时自动快照当时汇率**，以后可按「当时汇率」或「当前汇率」用任意币种回看
- 💾 **导入 / 导出** —— 一键导出备份（复制文字或下载 .json），换设备时导入即可
- 🌗 **深浅色** —— 跟随系统，也可手动切换

## 使用

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建。

手机上建议**添加到主屏幕**，像个 App 一样随手就能记。

### 汇率说明

汇率是内置的**近似值**，在 ⚙ 设置里可随时手动修改。每笔记录会保存当下的汇率快照，所以即便以后改了汇率，"按当时汇率"回看依然准确。

### 数据与备份

所有数据保存在浏览器本地存储（localStorage）里：

- 换设备、清理浏览器数据前，记得用 ⚙ → **导出** 做一份备份
- 在新设备打开后用 ⚙ → **导入** 粘回去即可

## 技术

单文件、零依赖的纯静态页面（HTML + CSS + 原生 JS）。字体用 Google Fonts 的 Bricolage Grotesque 与 Space Mono。
